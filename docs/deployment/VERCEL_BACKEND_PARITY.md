The existing PHP code stays in the repository and on the school workstation. Never deploy the PHP package to Vercel.

The five WEB PHP endpoints were confirmed from `tools/web_allowlist.txt`, `tools/build_web.py`, and browser call sites. `admin/admin-mfa-auth.php`, `config/supabase-server.php`, `students/mail_config.php`, and three PHPMailer classes are include-only dependencies. `EntryExitMonitoring/admin/.htaccess` only adds no-cache behavior to settings. Local engine routes, event email, registration trigger, and `delete_engine_log.php` are not WEB routes and remain LOCAL_GATE.

## Shared security contract

`server/admin-auth.ts` validates the bearer through Supabase Auth `getUser(token)` **before** examining the token's signed `sub`, `role=authenticated`, and `aal=aal2` claims. It then loads the active `admins` profile through a server-only service-role client. The browser's session storage, role fields, and request JSON are not authority. The service key exists only in Function environment variables. AAL1 and suspended users are denied. Browser controls remain navigation aids; RLS remains the data boundary for direct Supabase calls. [Supabase Auth MFA guide](https://supabase.com/docs/guides/auth/auth-mfa) and [Admin API reference](https://supabase.com/docs/reference/javascript/auth-admin-createuser) describe the SDK operations.

The PHP QR sender accepts arbitrary `email` and arbitrary fallback QR text. That is an authenticated SMTP relay and can issue rollover-unsafe QR codes. The Vercel route intentionally tightens this: only a known student UUID, server-verified recipient, and `student_uuid:<UUID>` payload are allowed. The old Event `sendQrCodes.js` WEB path is upgraded to UUID and maps its legacy display fields to the current `students.stud_id`, `current_grade_level`, and persistent section data; LOCAL_GATE still uses its existing PHP route and payload. No student row is changed by sending.

## Frontend routing and coexistence

`config/config.js` exposes `AppDeployment.apiRoute()` and routes the five calls to same-origin `/api/*` only in `WEB`. `adminAal2Fetch()` uses the same mapping. In `LOCAL_GATE`, the original `.php` URLs are returned unchanged. Vercel Preview and Production use their own origin and the same relative API routes. There is no wildcard CORS header. The five existing PHP files are retained for fallback and local use.

## Apache rules and Vercel equivalents

Apache `Options -Indexes` and `<Files>` denial of `config/supabase-server.php`, `admin/admin-mfa-auth.php`, and PHPMailer/mail includes become **physical exclusion from `dist/web/`**; `server/*.ts` has no public route. The Apache no-cache header for Entry & Exit settings becomes a `vercel.json` header. API `Cache-Control: no-store` and `X-Content-Type-Options: nosniff` are set by each JSON response and Vercel headers. The generated browser `config/.env.js` contains a publishable/anon key only; its no-cache header is in `vercel.json`. Vercel's `outputDirectory: dist/web` serves only the allowlisted static tree. `api/*.ts` is compiled as Node Functions by Vercel, separate from static output. No SPA catch-all rewrite is needed because pages are independent HTML files. See [Vercel Node Functions](https://vercel.com/docs/functions/runtimes/node-js) and [build output configuration](https://vercel.com/docs/builds/configure-a-build).

## Test limits before a deployment

The offline contract suite uses the same status and side-effect expectations as existing PHP tests with injectable fake gateway identities. It never grants permissions merely because a fake token has AAL2: the fake Auth verifier must recognize the token first. The offline build serves static management pages without PHP, Python, Flask, or webcam code. `npm run test:secrets` scans WEB source and output without printing values. Full browser login/MFA, live Auth/Data effects, SMTP delivery, password-reset redirect, Vercel Function packaging, and HTTPS behavior require a development project and/or Vercel Preview with disposable identities and carefully scoped credentials. The school workstation's live camera behavior remains a separate manual regression.
